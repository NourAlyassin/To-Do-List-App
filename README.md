# Task13 - To-Do List App


A simple task manager built with PHP and MySQL, following the EraaSoft playlist. It performs full CRUD operations — adding, viewing, editing, and deleting tasks — and stores everything in a tasks table with the fields id, title, is_completed, and created_at. The project files are organized into clear folders for the database connection, the task logic, and the pages the user interacts with.


Core Features

Add a new task with a title
View all tasks in a list
Mark a task as completed
Edit an existing task's title
Delete a task
Database


Table tasks — id, title
Project Files

config/ — database connection
tasks/ — CRUD logic (show, add, edit, delete)
index.php — main page displaying the task list
style.css — basic styling
Tech Stack

PHP
MySQL
